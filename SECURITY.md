# Security Policy

## Supported Versions

Huia takes security seriously. Security updates are applied to the active development branch and released as patch versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not open public GitHub issues or discussions for suspected security vulnerabilities.**

If you discover a security issue or vulnerability in Huia, please report it via GitHub's private vulnerability reporting feature:

1. Navigate to the **Security** tab of the Huia repository on GitHub.
2. Select **Advisories** and click **Report a vulnerability**.
3. Provide a detailed summary including:
   - A clear description of the vulnerability.
   - Affected package(s) and version(s).
   - Step-by-step reproduction instructions or proof-of-concept code.
   - Any proposed remediation if known.

Alternatively, you may contact the maintainers directly via email at `security@aymanelfaki.com` (or project maintainer contact).

### What to Expect

- **Acknowledgment**: We aim to acknowledge reports within 48 hours.
- **Assessment**: We will evaluate the impact, severity, and reproduction steps.
- **Coordination**: We will keep you informed of remediation progress and coordinate disclosure timing.
- **Fix & Advisory**: We will publish a patched release along with a CVE/GitHub Security Advisory crediting your responsible disclosure if desired.
